# PROКиберурок

Лендинг по Figma, обычные HTML/CSS/JavaScript. Для публикации загрузите index.html, style.css, app.js и папку assets на статический хостинг.

Локальный запуск из папки проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173 . Также можно открыть index.html двойным щелчком; для встроенной Яндекс Формы нужен интернет.

Кнопка открывает диалог со встроенной Яндекс Формой. Есть прямая ссылка, закрытие кнопкой, Escape и кликом вне окна; после закрытия фокус возвращается на кнопку. Заявки обрабатывает Яндекс Форма. Сайт не хранит ответы.

Версии: компьютер, планшет и телефон; проверены ширины 1440, 768, 360 и 320 пикселей. Все изображения и иконки из макета сохранены в assets.

## Варианты подачи мероприятия

1. «Практики, которые работают» — текущая версия по макету. Призыв: «Поделитесь педагогической находкой». Подходит для широкого сбора опыта.
2. «Одно занятие. Ваша находка. Опыт для 215 школ» — акцент на распространении конкретного решения. Призыв: «Предложить своё решение». Числа 215 школ и более 600 педагогов взяты из уточнения организатора, а не из старых данных документа.
3. «PROКиберурок: лаборатория учительских решений» — акцент на совместной работе 17 ноября 2026 года. Призыв: «Поделиться практикой и заявить об участии». Приглашение подтверждается организатором отдельно.

Название конкурса и обещания наград следует добавлять после утверждения номинаций, критериев, призов и условий. Срок подачи, место и время не указаны в материалах и не придуманы.
